# 📝 React Noter

> A clean, minimal note-taking app built with React and Tailwind CSS.

## ✨ Features

- 📌 Add notes with a title and description
- ⚡ Notes render instantly on submit
- 📭 Empty state when no notes exist
- 📱 Fully responsive — mobile and desktop
- 🌙 Dark themed UI

## 🚀 Getting Started

### Prerequisites

- Node.js installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/adnananjum/react-noter

# Navigate to the project
cd react-noter

# Install dependencies
npm install

# Start the development server
npm run dev
```
